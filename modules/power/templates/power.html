System Power
Restart
Restarts the whole system. Every service stops and comes back up, so this interface and all connections through the gateway are down for a minute or two.
Shut down
Powers the system off. It stays off until someone starts it again at the machine itself, so only do this if you can.
Restart the system?

The system will restart in a few seconds. This interface and every connection through the gateway will be unavailable for a minute or two.

Tunnels and services start again by themselves when it is back.

Shut down the system?
The system will power off in a few seconds and will not come back by itself. Nothing can start it from here - someone has to power it on at the machine.
